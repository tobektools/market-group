# Tobek Tools V1 — First Look

Website frontend statis sebagai fondasi pengembangan Tobek Tools.

## Perubahan V1
- Nama brand pada website: **Tobek Tools**.
- Tema halaman pelanggan diubah ke **background putih** dengan aksen orange dan header/footer navy gelap.
- Ditambahkan area media sosial.
- Ditambahkan pilihan komunikasi: **Chat di Website** dan **WhatsApp**.
- Chat website masih berupa demo UI dan nantinya dapat dihubungkan ke sistem Help Center/Ticket.
- Nomor WhatsApp dan link media sosial masih placeholder sampai data resmi diberikan.
- Produk yang tampil masih data demo; katalog asli akan dimasukkan melalui Mass Upload.

## Menjalankan
Buka `index.html` di browser.

## Tahap berikutnya
Hubungkan frontend ke database/API, Admin Dashboard, Mass Upload/Mass Update, autentikasi, inventory, order, dan modul commerce.
